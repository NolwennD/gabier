## New in 0.5.0

- **`gabier mcp`, the MCP server.** An agent host that speaks [MCP](https://modelcontextprotocol.io) gets gabier as
  tools, over stdio: one tool per operation (`diagnostics`, `rename`, `rename-token`, `organize-imports`, `cleanup`, the
  four `extract-*`, `move-type-to-file`, `move`, `inline`, `create`, `references`, `actions`, `apply-action`, `status`),
  with a typed input schema, a `guide` tool that answers which tool does a task, the instructions of the server, and the
  daemon started in the background when the host connects. It answers both eras of the protocol (`server/discover` of the
  2026-07-28 revision, `initialize` of the earlier ones). The server is part of the native `gabier`: for Claude Code,
  `claude mcp add gabier -- gabier mcp`. See [`mcp`](https://github.com/NolwennD/gabier/blob/v0.5.0/docs/commands/mcp.md).
- `gabier cleanup` now prints the warnings of the daemon when there is nothing to change, as `organize-imports` does.
- Inside: the cli is built as a hexagon (the command line and the MCP server are two primary adapters over one entry
  point that runs an operation; the daemon is behind a port). No other change to the commands.

The MCP server has not been used with every host: report what a host does with it.
